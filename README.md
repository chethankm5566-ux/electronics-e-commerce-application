# 🛒 Electronics E-Commerce Application

A front-end based Electronics E-Commerce web application built using HTML, CSS, and JavaScript. This project allows users to browse products, manage their cart and wishlist, and perform basic authentication like login and signup.

---

## 🚀 Features
- User Login & Signup
- Product Listing (Home Page)
- Add to Cart functionality
- Wishlist management
- Responsive UI
- Dynamic behavior using JavaScript

---

## 🛠️ Technologies Used
- HTML5  
- CSS3  
- JavaScript  

---

## 📂 Project Structure
- home.html  
- login.html / login.js / login.css  
- signup.html / signup.js / signup.css  
- cart.html / cart.js / cart.css  
- wishlist.html / wishlist.js  
- home.js / homeStyle.css
